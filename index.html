Explain It

1. How does the app change a sound wave into binary? Name the three steps.
Step 1: sample the wave's height at equal time intervals. Step 2: round each height to the nearest level, then Step 3: write each level in binary with the chosen number of bits.

2. Does 2 bits or 6 bits give more detail?

3. Which test has the longest wavelength?
Test B has the longest wavelength because it has the lowest frequency (200 Hz). Wavelength = 343 ÷ frequency, so a higher frequency means a shorter wavelength.

4. What was the hardest stage to build, and how did you fix it?
The hardest part was handling invalid input, because empty fields turned into 0 and passed as numbers with no warning. I fixed it by checking for blank values first, then checking each range one by one, so every bad input now shows a clear message.
